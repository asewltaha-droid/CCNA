# Jeremy's IT Lab – CCNA Practical Labs

## Overview

This repository contains my practical networking labs based on Jeremy's IT Lab CCNA course.

I use Cisco Packet Tracer to practice networking concepts, configure Cisco devices, and develop my hands-on networking skills.

## Topics Covered

- Basic Router and Switch Configuration
- Device Security
- VLANs and Trunking
- IPv4 Subnetting
- Routing
- Network Services
- Access Control Lists (ACLs)
- Network Address Translation (NAT)
- WAN Technologies
- Network Automation

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- Git and GitHub

## Repository Structure

Each lab is organized in its own folder and includes Packet Tracer project files and documentation.

## Learning Goals

- Develop practical CCNA networking skills.
- Understand Cisco IOS commands.
- Configure and troubleshoot networks.
- Practice network security.
- Build confidence with real-world networking scenarios.

**Note:** These labs are completed as part of my personal CCNA learning journey, following Jeremy's IT Lab course.
